# Tutorial Files

This folder contains starter artifacts for the Windows Active Directory isolated FSDR drill tutorial:

- `fsdr-ad-sandbox-tags-template.json`: reference list of free-form tag keys and placeholder values for a source Windows instance.
- `fsdr-moving-instance-vnic-mapping-example.json`: example standard moving-instance VNIC mapping shape for failover and switchover.
- `windows-ad-isolation-validation.ps1`: PowerShell checks to confirm the recovered drill instance cannot reach Active Directory.

Replace all placeholder OCIDs, domain names, and tag names before using the files.
